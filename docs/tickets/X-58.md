## Суть

`.env` установки и `collector.env` создаются с правами по умолчанию. Внутри — `MASTER_KEY`, `SECRET_KEY`, `COLLECTOR_TOKEN`, пароль базы. На Windows файл в папке установки читается **любой локальной учётной записью**, на macOS/Linux — любым процессом пользователя и всем, у кого есть доступ к каталогу.

Заведено `init.bat`/`init-env.sh` (`X-17`), `bootstrap.py` (`S1-10`) и `make init`. То есть мест три, и ни одно ACL не выставляет.

## Почему это не блокер и почему всё-таки тикет

У первого пользователя машина одна и учётка на ней одна — практической разницы сегодня нет. Но:

- `COLLECTOR_TOKEN` глобален для установки (`SPEC.md` §5.3, v1.19): им пишутся сделки в **любой** счёт;
- `MASTER_KEY` расшифровывает пароли торговых счетов;
- инструкция `T-01` будет говорить «положите папку в корень `C:`», а корень диска на Windows по умолчанию читаем всем.

Цена ошибки высокая, вероятность сегодня низкая — отсюда `Todo`, а не «сейчас».

## Что сделать

1. Решить, где ставятся права: в трёх местах создания или одним общим шагом.
2. Windows — `icacls` на владельца и `SYSTEM`, без наследования. Проверить, что задача Планировщика под тем же пользователем файл читает.
3. macOS/Linux — `chmod 600`.
4. Проверить, что `make update` (`T-02`) права не сбрасывает распаковкой архива поверх.
5. Решить, что делать с уже созданными файлами: чинить при старте или молчать.

## Acceptance criteria

- Права выставляются во всех местах создания, а не в одном.
- Прогон на Windows подтверждает, что коллектор из Планировщика файл читает.
- `update` права не теряет.
