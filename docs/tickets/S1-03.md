Задача и Definition of Done — `SPEC.md` §12, пункт `S1-03`. Здесь только дельта над спекой.

## ⚠️ Заблокирована фикстурами

DoD требует: «8 фикстур проходят». Фикстур нет — `docs/fixtures.md` не существует, реальной выгрузки с MT5 не было. Это **единственная** задача этапа 1, которую нельзя честно закрыть без данных.

Писать сборщик на выдуманных данных значит проверить своё понимание документации, а не поведение брокера. Именно здесь всплывают частичные закрытия, свопы отдельными сделками и балансовые операции.

## Что уже готово

`S1-02` даёт функцию `deal_role(deal_type: str, position_id: int) -> "trade" | "adjustment" | "excluded"`. Сигнатура намеренно принимает строку и число, а не объект: **сборщик классифицирует строки из БД**, включая приехавшие прошлыми батчами, а не результат нормализации текущего.

- `trade` → объём, цена, направление, `deals_count`, `open_time`/`close_time`, `close_reason`
- `adjustment` → только `profit/commission/swap/fee` в суммы
- `excluded` → не участвует

Вторую копию этого правила не заводить — в этом весь смысл вынесенной функции.

`to_utc()` оттуда же понадобится для `open_positions[].time_server`: по `SPEC.md` §5.3 п.5 открытая позиция без сделок создаётся как `status='open'`, и её `open_time` — это `time_utc`.

## ⚠️ Развилка, переданная из `S1-02`

**Торговая сделка с `position_id = 0`.** `deal_role("buy", 0)` возвращает `trade`: §6.2 исключает только `balance`/`credit`/`other`, про `buy` с нулевым `position_id` там нет ни слова.

Значит все такие сделки со всего счёта попадут в одну группу и породят одну общую позицию — бессмысленную. Отбрасывать их — правило, которого в спеке нет, поэтому вводить его молча нельзя.

Решать после того, как станет известно, встречается ли это на живых данных (`docs/mt5-assumptions.md`, пункт 8).

## Обязательное свойство

DoD называет идемпотентность отдельно: **двойной прогон даёт тот же результат**. Проверять прогоном, а не рассуждением про чистоту функции.

Плюс «два батча с перекрытием» — то есть пересборка позиции, часть сделок которой уже была.
